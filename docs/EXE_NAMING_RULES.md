# 📦 EXE 文件命名规则

## 概述

本项目采用基于时间的版本号命名规则，确保每个构建版本都有唯一且可追溯的标识。

## 命名格式

### 标准格式

```
QML_YYMMDD_HM.exe
```

**示例**: `QML_260521_A2.exe`

### 格式详解

| 部分 | 说明 | 示例 | 备注 |
|------|------|------|------|
| **QML** | 项目缩写 | QML | QEMU Manager for LoongArch |
| **YYMMDD** | 日期（简写） | 260521 | 26年05月21日 |
| **H** | 小时段代码 | A | 字母表示2小时时段 |
| **M** | 分钟段代码 | 2 | 数字表示10分钟时段 |

---

## 📅 日期代码（YYMMDD）

使用6位数字表示日期：

- **YY**: 年份后两位（00-99）
- **MM**: 月份（01-12）
- **DD**: 日期（01-31）

**示例**:
- `260521` = 2026年05月21日
- `251231` = 2025年12月31日
- `240101` = 2024年01月01日

---

## ⏰ 时间代码（HM）

### 小时段代码（H）- 字母

每2小时为一个时段，用字母表示：

| 代码 | 时间范围 | 代码 | 时间范围 |
|------|----------|------|----------|
| **0** | 00:00 - 01:59 | **G** | 14:00 - 15:59 |
| **A** | 02:00 - 03:59 | **H** | 16:00 - 17:59 |
| **B** | 04:00 - 05:59 | **I** | 18:00 - 19:59 |
| **C** | 06:00 - 07:59 | **J** | 20:00 - 21:59 |
| **D** | 08:00 - 09:59 | **K** | 22:00 - 23:59 |
| **E** | 10:00 - 11:59 | | |
| **F** | 12:00 - 13:59 | | |

### 分钟段代码（M）- 数字

每10分钟为一个时段，用数字表示：

| 代码 | 分钟范围 |
|------|----------|
| **0** | 00 - 09 分 |
| **1** | 10 - 19 分 |
| **2** | 20 - 29 分 |
| **3** | 30 - 39 分 |
| **4** | 40 - 49 分 |
| **5** | 50 - 59 分 |

## 🗂️ 生成的文件类型

每次打包会生成以下文件：

### 1. **主发布文件**（带简写版本号）
```
QML_260521_A2.exe
```
- ✅ 最新版本标识
- ✅ 用于正式发布和分享
- ✅ 文件名简短易读

### 2. **完整日期备份**（带完整年份）
```
QML_20260521_A2.exe
```
- 📦 长期存档使用
- 📦 避免跨世纪混淆
- 📦 便于按年份分类管理

### 3. **无版本号版本**（方便日常使用）
```
Deepin_VM_Manager.exe
```
- 🔧 开发测试使用
- 🔧 无需关心版本号
- 🔧 固定名称便于脚本调用

### 4. **旧版格式**（兼容性保留）
```
Deepin_VM_Manager_20260521_A1.exe
```
- 📜 历史版本保留
- 📜 逐步淘汰中
- 📜 仅用于向后兼容

## 💡 最佳实践

### ✅ 推荐做法

1. **发布时使用简写版本**
   ```
   QML_260521_A2.exe
   ```

2. **定期归档到 releases 文件夹**
   ```
   releases/
   ├── QML_260521_A2.exe
   ├── QML_260520_K4.exe
   └── QML_260519_G2.exe
   ```

3. **Git 标签对应版本号**
   ```bash
   git tag v260521-A2
   git push origin v260521-A2
   ```

4. **更新日志中标注版本**
   ```markdown
   ## [QML_260521_A2] - 2026-05-21
   
   ### Added
   - 新功能描述
   
   ### Fixed
   - Bug修复描述
   ```

### ❌ 避免做法

1. **不要手动重命名版本号文件**
   - 让构建脚本自动生成

2. **不要删除旧版本**
   - 至少保留最近10个版本

3. **不要混用不同命名规则**
   - 统一使用 QML_YYMMDD_HM 格式
